# charity-installer

سكربت تنصيب **منصة إدارة المشاريع الخيرية** على خادم جديد، لمؤسسة بلا
تقني.

على خادم لينكس جديد (Ubuntu أو Debian)، من طرفية الخادم:

```bash
curl -fsSL https://raw.githubusercontent.com/Shadi1985/charity-installer/main/bootstrap.sh | sudo bash
```

1. يسأل عن اسم المؤسسة والنطاق والبريد
2. يولّد مفتاح وصول **على الخادم نفسه**، ويعرض سطرًا يبدأ بـ `ssh-ed25519`
3. **أرسل هذا السطر إلى مطوّر المنصة.** ليس سرًّا
4. حين يفعّله المطوّر يكمل السكربت وحده: يستنسخ المنصة، ويثبّت Docker،
   ويبني المنصة، ثم يطبع رابط معالج التهيئة

إن أُغلقت النافذة أثناء الانتظار، أعد السطر نفسه فيُكمل من حيث توقف.

## ما في هذا المستودع

هذا الملف و `bootstrap.sh` فقط. **لا كود للمنصة هنا ولا أسرار.** المنصة
في مستودع خاص، ولا يصل إليها الخادم إلا بعد أن يضيف المطوّر مفتاحه.
